## 1. UX/UI и юзабилити

### Оценки
| Критерий | Оценка |
|----------|--------|
| UVP ясность | 7/10 |
| Дизайн | 8/10 |
| User Journey | 6/10 |
| Мобильная адаптация | 8/10 |

### Сильные стороны
- Hero-блок за 3 секунды доносит суть: "48,000+ OEM parts from Korea, 7-14 days"
- Тёмная цветовая гамма с синим акцентом — авторитетно, ассоциация с автоиндустрией
- Адаптивная сетка: 2→3→4 колонки в каталоге, fluid-типографика через clamp()
- Sticky header с blur-эффектом, корзина с счётчиком — стандарт e-commerce
- Плавающие кнопки WhatsApp/Telegram — быстрый доступ к менеджеру

### Проблемы User Journey
- **Разрыв в checkout:** пользователь привык к "оплатил → получил". Здесь: "отправил заявку → жди звонка менеджера". Это friction point — нет понимания, когда и как произойдёт оплата
- **VIN Check уходит в Telegram:** клик на "Check VIN" выбрасывает из сайта в мессенджер — теряется часть аудитории, которая не использует Telegram
- **Нет поиска в header:** для сайта с 48k товаров поиск должен быть в шапке, а не только на странице каталога
- **Карточка товара без фото:** многие товары показывают "No image" placeholder — критично для конверсии

### Рекомендации по UI
- Добавить поисковую строку в header (мобиль — иконка лупы, десктоп — поле с placeholder)
- На checkout чётко объяснить: "Менеджер свяжется в течение 30 минут" с таймлайном шагов
- Добавить индикатор прогресса в checkout (шаг 1/3, 2/3...)
- Кнопку "Check VIN" дополнить текстом "via Telegram" чтобы не было сюрприза при клике

## 2. Маркетинг и конверсия (CRO)

### Триггеры доверия

**Есть:**
- Гарантия оригинальности OEM
- Фото/видео-отчёт до отправки
- Реальный адрес в Асане, Корея
- Близость к заводу Hyundai Mobis
- Бесплатная проверка VIN
- Поддержка менеджера на всех этапах

**Не хватает (критично):**
- **Отзывы клиентов** — ноль социального доказательства
- **Счётчик заказов** — "500+ заказов доставлено"
- **Фото реальных отправок** — упаковка, трек-номера
- **Сертификаты / партнёрство** — связь с Mobis
- **Гарантия возврата** — что если деталь не подошла?
- **Время ответа** — "отвечаем за 30 минут"

### Friction-анализ воронки

```
Каталог (низкое) → Корзина (низкое) → Заявка (среднее) → Ожидание (ВЫСОКОЕ) → Оплата (вне сайта)
```

**Главная проблема:** после нажатия "Submit Request" пользователь попадает в неизвестность. Нет информации: когда свяжутся? Как платить? Можно ли отменить? Западный покупатель (EN-аудитория) привык к instant checkout с картой — модель "менеджер перезвонит" вызывает недоверие.

### Оценка CTA-элементов

| CTA | Оценка |
|-----|--------|
| Browse Catalog | Хорошо — чёткое действие, заметная кнопка |
| Check VIN | Средне — уводит в Telegram без предупреждения |
| Submit Request | Слабо — "request" звучит неуверенно, не "order" |
| WhatsApp / Telegram кнопки | Отлично — всегда доступны, анимация привлекает |
| Add to Cart | Хорошо — feedback "Added" + иконка |

## 3. Контент и копирайтинг

### Качество английского текста

Тексты **грамматически корректны** и читаются естественно. Нет "translationese" — ощущения машинного перевода. Терминология консистентна: "Genuine OEM Parts", "Hyundai, Kia, Genesis" (всегда в этом порядке), "7-14 days".

**Но:** тексты *информативны*, а не *продающие*. Для международного рынка нужен более эмоциональный копирайтинг. Сравните:

- Сейчас: "Only original Hyundai, Kia, and Genesis parts from the manufacturer."
- Лучше: "Every part comes with a Mobis hologram — the same part your dealer installs, at half the price."

### Чего не хватает в FAQ

Сейчас 5 вопросов — минимум для продающего сайта. Западного покупателя волнует:

- **"What if the part doesn't fit?"** — политика возврата/обмена
- **"Do you provide tracking?"** — отслеживание посылки
- **"Are there customs duties?"** — таможня и пошлины
- **"How do I know it's genuine?"** — как проверить оригинальность
- **"Can I order parts not in the catalog?"** — индивидуальный заказ
- **"What payment methods do you accept?"** — конкретные способы оплаты

### Контент-пробелы по страницам

| Страница | Проблема |
|----------|----------|
| Home | Нет блока отзывов, нет "Recently shipped" с фото реальных заказов, нет логотипов брендов (Hyundai/Kia/Genesis) |
| About | Упоминает фото/видео-отчёты, но не показывает ни одного примера. Нет фото команды / офиса |
| How It Works | Не объясняет способы оплаты. Шаг 4 "Payment & Delivery" — но как именно платить? |
| Product | Нет описания деталей (для чего, куда ставится). Только номер, название, цена, совместимость |

## 4. SEO и техническая оптимизация

### Что сделано хорошо
- Schema markup: Organization, WebSite, Product, BreadcrumbList, FAQPage
- Hreflang alternate для ru/en/ar на каждой странице
- Canonical URL на всех страницах
- OpenGraph теги на каждой странице
- Sitemap index с 27 чанками (покрывает все 48k товаров)
- Title шаблоны уникальны для каждой страницы

### H1-H3 иерархия — проблемы

| Страница | Проблема |
|----------|----------|
| Home H1 | "Genuine Korean Car Parts" — хорошо, но нет "buy" / "order" / "shop" |
| Catalog H1 | "Parts Catalog" — слишком общий. Лучше: "Korean Car Parts Catalog — Hyundai, Kia, Genesis OEM" |
| How It Works H1 | "How It Works" — пусто для SEO. Лучше: "How to Order Korean Car Parts Online" |
| Contact H1 | "Contact Us" — можно усилить: "Contact Us — Order Genuine Korean Parts" |

### Упущенные SEO-возможности
- **Нет блога:** статьи типа "How to find your Hyundai part number", "OEM vs aftermarket" дадут органический трафик
- **Нет LocalBusiness schema:** адрес в Асане не размечен для Google Maps
- **Нет Review/Rating schema:** при наличии отзывов — rich snippets со звёздами в Google
- **Нет OG-изображения:** при шеринге в соцсетях — нет брендированной картинки
- **Product description пуст:** meta description товаров шаблонный, нет уникального текста для индексации
- **Целевые запросы не покрыты:** "buy Hyundai parts online", "Korea car parts shipping", "Genesis OEM parts worldwide"

## 5. Приоритетные рекомендации (7 пунктов)

### Quick Wins (реализуемы за 1-2 дня)

**1. Добавить социальное доказательство** `CRO` `КРИТИЧНО`

Блок "Customer Reviews" или "Recently Shipped" на главной. Даже 3-5 реальных отзывов с фото упаковки кратно повысят доверие. Без отзывов сайт выглядит как шаблон, а не работающий бизнес. Можно начать с Telegram-скриншотов благодарностей.

**2. Переработать checkout flow** `UX` `КРИТИЧНО`

Сейчас после "Submit Request" — пустота. Нужно:
1. Изменить "Submit Request" → "Place Order" (уверенность)
2. На странице успеха — чёткий таймлайн: "Manager will contact you within 30 min via WhatsApp/Telegram"
3. Добавить FAQ "How do I pay?" прямо под формой
4. Показать иконки способов оплаты (bank transfer, PayPal и т.д.)

**3. Расширить FAQ до 10-12 вопросов** `SEO + CRO`

Добавить: возврат/обмен, таможенные пошлины, отслеживание посылки, способы оплаты, заказ деталей не из каталога, проверка оригинальности. Каждый вопрос = потенциальный rich snippet в Google + снятие возражения перед покупкой.

**5. SEO-оптимизация H1 заголовков** `SEO`

- "Parts Catalog" → "Korean Car Parts Catalog — Hyundai, Kia, Genesis OEM"
- "How It Works" → "How to Order Korean Car Parts Online"
- "Contact Us" → "Contact Us — Order Genuine Korean Parts"

**7. Логотипы брендов + партнёрские бейджи** `CRO`

Добавить секцию с лого Hyundai, Kia, Genesis, Mobis на главную. Визуальная ассоциация с крупными брендами мгновенно повышает доверие. Также добавить бейджи: "Ships from Korea", "100% OEM Verified", иконки способов доставки (EMS, DHL).

### Medium (1-2 недели)

**4. Поиск в header + автодополнение** `UX`

При 48k товаров поиск по номеру детали — основной сценарий. Покупатель знает part number и хочет вбить его мгновенно. Сейчас нужно идти в каталог. Добавить поиск в шапку с подсказками (по part number и названию).

### Long-term (месяц+)

**6. Блог с контент-маркетингом** `SEO`

Статьи: "How to find your Hyundai part number by VIN", "OEM vs Aftermarket parts — what's the difference", "Complete guide to importing car parts from Korea". Каждая статья = точка входа из Google + демонстрация экспертизы.
