## 1. SEO — критичные проблемы

### 1.1. `<html>` без атрибута `lang` — КРИТИЧНО

Живой HTML: `<html class="space_grotesk_...">` — ни `lang`, ни `dir`.
`HtmlLang.tsx` ставит их через `useEffect` **на клиенте** — краулеры без JS и скринридеры при загрузке видят страницу без языка. Для `/ar` это ещё и вспышка LTR-раскладки.

**Фикс:** рендерить `<html lang={lang} dir={dir}>` серверно. Стандартный паттерн next-intl — `<html>` в `src/app/[lang]/layout.tsx` (сейчас он в корневом `src/app/layout.tsx`, а `[lang]/layout.tsx` вешает `lang`/`dir` на `<div>` — это костыль). Сверить с доками в `node_modules/next/dist/docs/` (нестандартная версия Next).

### 1.2. Русские названия категорий на английской странице — КРИТИЧНО

В SSR-HTML `/en/catalog` присутствуют: **Шасси, Салон, Кузов, Коробка передач, Двигатель**.
Причина: `src/app/[lang]/catalog/page.tsx:96` — `name: c.name_ru` без учёта локали. API-роут (`route.ts:153`) локализует правильно, а серверный рендер — нет.

Кириллица в EN-странице портит определение языка страницы и выглядит сломанно для пользователя.

**Фикс (одна строка):**
```ts
name: lang === "ru" ? c.name_ru : (c.name_en ?? c.name_ru),
```

### 1.3. Каталог невидим для краулеров глубже первой страницы — СТРУКТУРНО КРИТИЧНО

Все категории, фильтры и пагинация — `<button>` + `pushState` + `fetch`. **Ни одной ссылки `<a href>`**. Googlebot не кликает кнопки:

- 48k+ товаров достижимы только через sitemap → индексация есть, но **внутренняя перелинковка нулевая** → товары не получают ссылочный вес → слабые позиции;
- страницы категорий не существуют как URL → запросы вида "hyundai engine parts", "kia body parts" ничем не ловятся.

**Фикс (самый важный по эффекту):**
1. SSR-страницы категорий с реальными URL: `/en/catalog/engine`, `/en/catalog/body`… (уникальные title/h1/description на категорию). Это же и посадочные страницы под средне-частотные запросы.
2. Пагинация ссылками: `<a href="?page=2">` (можно перехватывать клик и оставлять SPA-поведение, но href обязан быть).
3. Сайдбар категорий — ссылки на категории, не кнопки.

⚠️ **Предупреждение:** индексируемыми делать только категории и пагинацию. Комбинации фильтров (цена, сортировка, поиск) оставить с canonical на чистый URL категории — иначе взрыв дублей и расход краул-бюджета.

### 1.4. Слабые title и H1

- Title: `Parts Catalog` — без бренда (шаблон "%s"), без ключей.
- H1: `Parts Catalog`.

**Фикс:** title → `Hyundai, Kia & Genesis OEM Parts Catalog | Caranalizer`, H1 → `Korean Car Parts Catalog — Hyundai, Kia, Genesis OEM` (уже было в AUDIT_EN.md, не внедрено).

### 1.5. Остальное по мелочи

| Проблема | Детали |
|---|---|
| Нет `x-default` hreflang на /catalog | Корневой layout его задаёт, но `generateMetadata` каталога переопределяет `languages` без x-default. Добавить `"x-default": ${BASE}/en/catalog` |
| Нет og:image | Подтверждено в HTML — при шеринге пустая карточка. Сделать брендированный OG 1200×630 |
| Нет ItemList JSON-LD | BreadcrumbList есть (хорошо). Добавить ItemList с первыми 24 товарами страницы |
| Картинки без оптимизации | `<img>` напрямую из Supabase Storage: без width/height (CLS), без srcset/resize (LCP). Перейти на next/image или Cloudflare Image Resizing |
| Сортировка по `name_ru` на EN | SSR первой страницы и default-sort в API упорядочены по русскому имени — для EN порядок выглядит случайным |
| Meta description заявляет "140,000+ parts" | Проверить соответствие реальному счётчику (на странице выводится total из category counts). Расхождение цифр в description/hero/каталоге подрывает доверие |

### 1.6. ⚠️ Cloudflare отдаёт 403 не-браузерным клиентам

Запрос без браузерного User-Agent получает **403**, с браузерным UA — 200. Googlebot скорее всего в белом списке Cloudflare, но так можно блокировать: Bing/другие поисковики, SEO-инструменты (Ahrefs/Semrush), **AI-краулеры (GPTBot, PerplexityBot, ClaudeBot)** — а рекомендации из AI-поиска для e-commerce уже заметный канал. Проверить в Cloudflare: Security → Bots → разрешить verified bots; посмотреть Security Events, кого реально режет.

## 3. Стратегия развития для мирового рынка

### 3.0. Предпосылка

Ниша — экспорт OEM-запчастей Hyundai/Kia/Genesis из Кореи. Глобальный спрос устойчив: парк Hyundai/Kia растёт везде, дилерские цены на OEM в 1.5–3 раза выше корейских. Конкуренты в EN-сегменте существуют, но ниша не выжжена — выигрывают ассортиментом (48k+ SKU — это преимущество), прозрачностью и доверием.

### 3.1. Приоритизация рынков

| Приоритет | Рынок | Почему | Что нужно |
|---|---|---|---|
| **1. Персидский залив** (UAE, KSA, Кувейт, Катар) | ar-локаль уже есть | Огромный парк Hyundai/Kia, жаркий климат = быстрый износ (подвеска, охлаждение, кондиционер), высокая платёжеспособность, близкая логистика из Кореи | Довести /ar до идеала (RTL, арабские названия категорий), пошлины/сроки для GCC на видном месте, оплата картой |
| **2. СНГ без РФ** (Казахстан, Узбекистан, Кавказ) | ru-локаль уже есть | Растущий парк корейских авто, знакомая модель «менеджер свяжется» не отпугивает | Kaspi-friendly оплата для KZ, сроки/доставка по странам |
| **3. Латинская Америка** (Чили, Перу, Эквадор, Колумбия) | новая локаль **es** | Hyundai/Kia — топ-бренды региона, дорогие оригинальные запчасти локально, привычка заказывать из-за рубежа | Испанская локаль — главный кандидат на 4-й язык. Не Бразилия (заградительные пошлины) |
| **4. Австралия / Новая Зеландия** | en уже есть | Большой парк, дорогие дилеры, привычка к международным заказам, английский | Только маркетинг + доставка/пошлины на страницах |
| **5. США / Канада / Европа** | en есть | Самые большие рынки, но и самая жёсткая конкуренция (RockAuto, местные OEM-дискаунтеры); в ЕС — VAT/таможня усложняют | Входить через long-tail (part number SEO) и цену, не через бренд-запросы |

### 3.2. Конверсионный фундамент (без него трафик бесполезен)

1. **Онлайн-оплата картой** (Stripe / PayPal / Paddle). Модель «отправил заявку → жди звонка» убивает конверсию у западной аудитории (уже отмечалось в AUDIT_EN.md). Это блокер №1 для всех рынков кроме СНГ.
2. **Отзывы на внешней платформе** — Trustpilot / Google Reviews. Внешние отзывы = доверие + Review schema (звёзды в выдаче).
3. **Страница Shipping & Customs по регионам** — сроки, стоимость, кто платит пошлину (DDP/DDU) для GCC / AU / US / LatAm. Также снимает главный страх покупателя.
4. **Политика возврата** отдельной страницей.

### 3.3. SEO-стратегия роста (по этапам)

**Этап 1 — техфундамент (1 неделя):** всё из раздела 1 этого аудита. Особенно категории-как-URL — без этого остальное SEO работает вполсилы.

**Этап 2 — посадочные страницы (2–4 недели):**
- Страницы категорий (из 1.3) с уникальными текстами.
- Страницы «бренд + модель»: `/en/parts/hyundai/santa-fe` — «Genuine Hyundai Santa Fe Parts». Данные fitment уже есть (parts_fitment, parts_vehicle_models). Это средне-частотник с покупательским интентом.
- Long-tail по part number уже покрыт 96k URL в sitemap — после появления перелинковки заработает сильнее.

**Этап 3 — каналы помимо органики:**
- **Google Merchant Center — бесплатные листинги.** Фид на 48k SKU из Supabase → бесплатное присутствие в Google Shopping. Для запчастей (поиск по part number) это очень конверсионный канал. Product JSON-LD уже есть — половина работы сделана.
- **eBay Motors** как отдельный канал сбыта с fitment-данными (US/AU/EU покупают запчасти именно там) — и заодно источник первых отзывов.
- **AI-поиск (AEO):** разрешить AI-краулеры в Cloudflare (см. 1.6), держать FAQ/schema в порядке — рекомендации «where to buy genuine Kia parts» в ChatGPT/Perplexity уже дают трафик.

**Этап 4 — контент (постоянно):** блог из AUDIT_EN.md остаётся в силе: «How to find your Hyundai part number by VIN» (+связка с VIN-ботом), «OEM vs aftermarket», гайды по моделям. Каждая статья — точка входа + внутренние ссылки на категории.

### 3.4. Локали — дорожная карта

1. Сейчас: ru / en / ar → довести качество (английские категории на /en — п.1.2; проверить, что на /ar категории не по-русски — та же строка кода).
2. **+es** (LatAm) — при появлении первых заказов/трафика из региона (смотреть GSC по странам).
3. Позже: de/pl (Европа) — только при подтверждённом спросе.
4. Валюты: KRW/USD уже есть; добавить AED/SAR для Залива — цена в родной валюте заметно поднимает конверсию.

### 3.5. Метрики

- GSC: клики/показы по странам и по типам страниц (категории vs товары) — еженедельно.
- GA4: конверсия в заявку по локали и стране.
- Доля товаров с фото (сейчас много «No image» — прямой удар по конверсии и Merchant Center: без фото фид не примут).
- Core Web Vitals (после фикса картинок LCP/CLS должны позеленеть).
